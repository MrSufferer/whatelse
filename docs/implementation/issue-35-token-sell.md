# Issue 35: token-quantity sell-back

LauncherToken trading version 2 supports `quoteSell(quantity)` and `sell(quantity,minNet,deadline)`. A sale burns the caller's requested base-unit quantity, floors the exact linear-curve integral once, rounds the 1% fee upward, splits the fee with the platform receiving odd-wei remainder, and sends net ETH. Reserve falls by gross value; fee liabilities rise separately. Nonzero delivery failure, expired deadline, insufficient holdings, and missed minimum revert atomically. The existing reentrancy guard covers both buys and sales. No fee withdrawal or administrative pause was added.

The detail page recognizes version 1 budget buys and version 2 buy/sell fixtures. Sales use exact 18-decimal token quantities, a default 1% tolerance with explicit higher options, and a quote timestamp plus 300 seconds. It presents gross, each fee share, net, average net execution price, both marginal prices, impact, and exact signed minimum. The chart traverses decreasing supply. A zero-net quote requires explicit burn confirmation even when gross is nonzero; zero minimum is signed exactly. Confirmation resets after input, account, mode, or quote changes. Rejected and reverted submissions retain the entered quantity; successful receipts refresh holdings and available capacity.

The predecessor's exact native input exception is reused for sales because fractional 18-decimal quantities and base-unit dust must remain representable. The block-pinned native wallet ETH read is retained alongside Scaffold `useTransactor` wrapping `wallet.writeContract`: the connected-wallet Balance component cannot share the quote's block snapshot. These are limited to the existing LauncherTrade trade surface. No new redesign or alternate wallet system is shipped; the browser evidence uses a local injected unlocked-Anvil wallet only.

Validation: 26 Foundry tests pass, including nine sell behavior tests and 256 fuzz cases. Public contract tests cover independently computed fractional/cap values, gross-one/net-zero and zero-gross burns, real tiny funded full unwind with one wei locked reserve dust, minimum/deadline/holding failures, failed ETH delivery rollback, and cross-path callback reentrancy. TypeScript, ESLint, and formatting checks pass for the frontend changes. ABI regeneration used the compiled local artifact.

Real wallet/browser evidence is in `launcher-token/evidence/issue35`. Eight successful app transactions were independently checked using Python Fraction integration and historical block accounting. A cap buy, fractional keyboard sale, capacity reopening, explicit zero-net confirmation, insufficient holdings, higher tolerance, signing rejection, wrong chain, full unwind, tiny funded unwind, actual stale-minimum/deadline reverted receipts, fresh retry, and disconnection were exercised. Responsive widths 375, 768, and 1280 have no horizontal overflow. The zero-net transaction has no ETH payout apart from gas spent by its sender.

This is a local-only release: chain 31337 RPC port 8546, frontend port 3002, immutable factory `0x5FbDB2315678afecb367f032d93F642f64180aa3`, token `0xa16E02E87b7454126E5E10d957A927A7F5B5d2be`. `NEXT_PUBLIC_LOCAL_RPC` configures an isolated local RPC only when local-chain mode is explicitly enabled. No public deployment or funded beta occurred. L2 finality remains unverified and activity indexing remains unavailable. Existing creation-only deployment artifacts are unchanged. Parent issue 24 and fee-claim work remain open.

The dynamic-address read/write exception is limited to this factory-child trade surface. Source verification: `useScaffoldReadContract.ts` resolves `contractName` with `useDeployedContractInfo` and supplies `deployedContract.address`; `useScaffoldWriteContract.ts` likewise resolves a named deployment and supplies `deployedContractData.address`. Factory-created LauncherToken addresses are selected at runtime and are not named static deployments, so LauncherTrade uses block-pinned `publicClient.readContract` and `wallet.writeContract` wrapped by Scaffold `useTransactor`. It retains Scaffold Address display and wallet connection infrastructure.
